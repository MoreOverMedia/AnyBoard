# *Board

A Dockerized Discord starboard bot for any emoji supporting:
- Unicode & custom emojis
- Per-guild thresholds
- Threads & webhooks

### Invite the Bot
[Click here to invite the bot](https://discord.com/oauth2/authorize?client_id=1461947379115753606&permissions=537259072&integration_type=0&scope=bot+applications.commands)

## Setup
1. Clone repo
2. Copy `.env.example` → `.env`
3. Add your Discord bot token
4. Run with Docker

## Environment Variables
- DISCORD_TOKEN (required)
- STARBOARD_CHANNEL_NAME
- STAR_THRESHOLD
